# 📄 PDF Summarization App (LLM)

This project is a PDF Summarization web application built using **Streamlit** and **LangChain**.

It allows users to upload a PDF file and generate a summary in just a few seconds using Large Language Models (LLMs).

---

## 🚀 Features

- 📤 Upload PDF files
- 📖 Extract text from PDF
- 🧠 Generate AI-powered summaries
- 🌐 Simple and interactive Streamlit interface

---

## 🛠️ Technologies Used

- Python 3.10+
- Streamlit
- LangChain
- Ollama (phi3) free
- PyPDF2
